# 🍽️ Chilli's Restaurant Dashboard (Excel)

## 📌 Project Overview

This project presents an interactive Excel dashboard designed to analyze restaurant sales performance, customer trends, and revenue insights.

The dashboard helps business owners make informed decisions by visualizing sales trends, product performance, and profitability metrics.

---

## 📊 Key Insights

- Revenue and sales trend analysis
- Best-performing menu categories
- Customer purchasing patterns
- Profitability tracking
- Interactive charts and visual summaries

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualization

---

## 🎯 Objective

To transform restaurant sales data into actionable insights that support better business decisions and operational performance.
